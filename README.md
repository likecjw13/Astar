# Astar · 路径规划实验室

**[打开 A* 寻路在线演示](https://likecjw13.github.io/Astar/)**

在 Windows 上可直接双击 `index.html` 离线打开。页面使用原生 HTML、CSS 和 JavaScript，无需安装依赖或启动服务。

## 教学操作

1. 选择内置实验，或自行设置地图尺寸、起终点和障碍物。自定义地图的行数和列数均可取 1 到 30。
2. 点击「单步执行」观察选点、终点判断、移入 Closed、邻格判断和代价更新。「下一轮」运行至本轮结束。自动运行支持调速和暂停，进度条可以回看已执行的任意步骤。
3. 用「查看节点」检查任意格子的 C 结构体，也可从 Open、Closed 表格定位节点。Open 按 f、行、列排序，Closed 按扩展顺序排列。
4. 日志随当前进度显示最近 120 条。「全部历史」可阅读本次搜索已生成的所有步骤。「清空」只清除主日志的当前显示，供后续继续记录。
5. 找到路径后点击「播放小车」，沿最短路径观看移动。运行数据里的计算耗时累计搜索与快照生成的时间，排除渲染与播放等待。
6. 点击「下载 .c」得到与当前地图匹配的源码，或复制 C 语言联动区的标准输入。

六个实验覆盖基础绕障、等长路径、更短路径更新、不可达、迷宫和随机地图。第三个实验中，节点 `(3,3)` 的 g 从 6 降至 4，父节点更新为 `(3,4)`。

## 算法原理

A* 使用 `f = g + h`。四方向移动的代价固定为 1，启发值 h 取到终点的曼哈顿距离。每轮按行优先遍历二维数组，只在 f 严格变小时替换候选。取出的节点若为终点，则沿父节点回溯，否则放入 Closed 并依次检查上、下、左、右。每个合法且未关闭的邻格仅在新代价严格降低时更新。坐标从 0 开始，顺序为行、列。

## C99 源码与测试

`c/astar.c` 是默认地图的完整示例。可用 GCC 编译，向程序提供文件中的标准输入，或从文件末尾直接读取默认配置。直接从终端运行时可输入完整的地图，也可通过终端的 EOF 结束输入以载入默认地图。

```powershell
gcc -std=c99 -Wall -Wextra c/astar.c -o astar.exe
Get-Content -Raw input.txt | .\astar.exe
node --test tests/astar.test.js
```

测试会用 BFS 对照边界场景和 1,000 张可复现的随机地图。若要同时编译并验证 C99 与 JavaScript 的选点、代价比较和路径一致性，在运行测试前设置 `ASTAR_CC`（如 `gcc`）和 `ASTAR_TEST_DIR`（用于编译的现有可写目录）。

## 文件分工

- `index.html` 与 `css/style.css` 定义页面和两种主题。
- `js/astar.js` 生成逐语句快照，未修改的节点在历史帧间共享。
- `js/source.js` 生成 C99、行号映射和标准输入。提交的 `c/astar.c` 由其生成。
- `js/visualizer.js` 渲染栅格、同步代码、节点结构体和集合表格。
- `js/app.js` 管理地图编辑、播放、回退、日志及导出。
- `tests/astar.test.js` 验证搜索、快照、C 代码与导出。
