# Astar · A* 寻路实验室

**[打开 A* 寻路在线演示](https://likecjw13.github.io/Astar/)**

双击 `index.html` 即可离线打开。无需安装依赖或启动服务器。

在 5 × 5 地图上点击格子添加或擦除障碍，使用“移动起点”和“移动终点”设置端点。编辑地图会回到第 0 步。选择“下一步”依次展开节点，“上一步”回看，也可以自动播放、暂停或调整速度。“重新演示”保留当前地图，“恢复示例”载入初始布局。

坐标从 0 开始，顺序为（行，列）。每次上下左右移动一格的代价为 1。A* 优先取出 f = g + h 最小的候选节点，其中 g 是已知起点到该节点的最小代价，h 是到终点的曼哈顿距离。同分时先按行、再按列取较小者。只有当终点被取出时，才显示最终路径。

默认示例从 (2,0) 到 (2,4)，要绕过中间的障碍，最短路径为 8 步。可以封住终点观察不可达情形，或让起点与终点重合观察零步路径。

- `index.html` 和 `style.css` 定义界面与布局。
- `search.js` 执行 A*，记录每轮搜索状态。
- `app.js` 处理编辑、播放和状态展示。
